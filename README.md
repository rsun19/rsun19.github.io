# Getting Started with running locally

1. Install Node.js (20.19+)

2. run `npm install`

3. run `npm start`

4. If you want to deploy onto GitHub Pages, run `npm run deploy`

5. To pull the latest résumé PDF from [robert_sun_resume](https://github.com/rsun19/robert_sun_resume), run `npm run sync-resume` (requires the `gh` CLI)
